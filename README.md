# 🎵 School Hits

> Um jogo de ritmo com inspiração em **Deltarune**, mecânicas que remetem a **Guitar Hero**, trilhas sonoras, vídeos de fundo e cutscenes para deixar tudo mais cinematográfico.

Este repositório contém a base de código do **School Hits**, desenvolvida na **Godot Engine**, pronta para você explorar, estudar, testar ou adaptar em novos projetos.

---

## ✨ O que já está por aqui

* **Gameplay de ritmo:** inspiração em *Deltarune* com uma fase que lembra *Guitar Hero*.
* **Imersão visual:** suporte a vídeos de fundo para deixar as músicas mais dinâmicas.
* **Tom cinematográfico:** estrutura pensada para incluir cutscenes entre os momentos do jogo.
* **Feito na Godot Engine:** código organizado para facilitar o reuso e a expansão.

---

## 📦 O que está ausente (e o que você precisa adicionar)

Para rodar o jogo completo, **apenas os arquivos pesados/externos não estão incluídos** neste repositório:

* **`assets/`** — coloque aqui os ativos do jogo (sprites, áudios/músicas, vídeos de fundo, fontes, efeitos sonoros etc.).
* **Cutscenes** — adicione aqui as cenas/vídeos cinematográficos para dar aquele clima extra à experiência.

---

## 🚀 Como rodar e reaproveitar o código

1. Baixe e abra a **Godot Engine**.
2. Crie um **novo projeto** na Godot.
3. **Cole os arquivos deste repositório** dentro da pasta do projeto criado.
4. Adicione seus **`assets`** e **cutscenes** nas pastas correspondentes e ajuste as referências conforme a sua organização.
5. Dê play e comece a testar ou modificar!
